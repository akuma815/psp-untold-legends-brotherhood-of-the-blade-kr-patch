적용 방법
1. 배포 ZIP을 새 폴더에 모두 압축 해제합니다.
2. UntoldLegends_KR_Patcher.exe를 실행합니다. Python이나 별도 패처 설치가 필요 없습니다.
3. 소유한 지원 원본 ISO와 새 한글 ISO의 출력 경로를 선택하고 패치를 적용합니다.
4. 완료 후 PPSSPP에서 생성된 ISO를 직접 엽니다. 원본과 기존 출력은 덮어쓰지 않습니다.
   패치 data·tools·manifest.json 등의 파일은 함께 유지하세요. data 내부 파일은 실행하지 마세요.

한글화 범위
원문 3,973개 중 3,569개와 분리 일지 2개, 합계 3,571개 문안.
게임 지도 25타일과 실제 로딩 문구 1개.
사용처 미확인 404개·별도 그래픽 13개·타이틀 배경 지도명·제작진은 원문 유지.
이름 입력은 원래 문자 범위를 유지합니다. 한글 이름 조합 입력은 추가하지 않았습니다.

검증 및 설정
실제 독립 EXE ISO 적용·검사, 잘못된 입력 거부, 결과 80파일 비교와 ISO 구조 검사를 통과했습니다.
PPSSPP에서 한글 프롤로그·타이틀·선별 표시를 확인했습니다.
추가 GUI 저장 검증 및 사용자 관찰은 PPSSPP_NOTES.txt를 확인하세요.
저장창이 보이지 않으면 게임별 그래픽 설정의 ‘버퍼 효과 건너뛰기’를 끄고 다시 실행하세요.
전체 본문 배치·후기·전투·엔딩·모든 저장/직업·실기·다른 버전의 검증은 완료하지 않았습니다.
패처 GUI 실제 클릭 검수와 전체 플레이 검수 완료를 뜻하지 않습니다.
기존 저장은 삭제/변환하지 않습니다. 옛 상태저장보다 새 실행의 일반 불러오기를 사용하세요.

명령행
UntoldLegends_KR_Patcher.exe --source "원본.iso" --output "새 한글판.iso" --report "결과.json"
기존 ISO 검사는 --output 대신 --verify-target "한글판.iso"를 사용합니다.
