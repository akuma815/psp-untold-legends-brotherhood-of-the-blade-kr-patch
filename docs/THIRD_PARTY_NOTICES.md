# 포함한 외부 자료

Galmuri 2.40.4의 Galmuri11.ttf와 Galmuri14.ttf를 변경하지 않고 포함합니다. 원문 라이선스는 `inputs/licenses/Galmuri-LICENSE.txt`이며 SIL Open Font License 1.1입니다. 원본 글꼴의 저작권/라이선스 표기는 해당 파일을 따릅니다. 이 글꼴을 단독으로 판매하지 않습니다.

Python 패키지는 requirements 목록으로만 지정하며 패키지 본체를 묶지 않습니다. 외부 어셈블러 실행 파일과 게임 추출 자산은 포함하지 않습니다. 선별 실제 스크린샷은 작업 결과 설명을 위한 자료이며 게임 자체의 권리는 원 권리자에게 있습니다.
