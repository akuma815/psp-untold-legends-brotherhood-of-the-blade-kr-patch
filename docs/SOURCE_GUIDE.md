# 공개 소스 구성

기존 PSP 저장소와 같은 README·img·docs·scripts·inputs·workspace·SOURCE_MANIFEST.json 구조를 사용합니다. `.github/ISSUE_TEMPLATE`에는 기존 방명록/버그 양식을 넣었습니다.

| 경로 | 내용 |
| --- | --- |
| `scripts/`, `config/` | 현행 원본 기반 빌드에서 관찰/선언한 코드와 설정 |
| `workspace/translation/` | 원고·번역 결정·범위 승인 |
| `inputs/pinned/` | 선별한 재현 메타데이터·공개 가능한 글꼴/글자 이미지/편집 마스크 |
| `inputs/PUBLIC_INPUTS.json` | 원본에서 만들 입력, 별도 제공이 필요한 입력, 복원할 메타데이터의 정확한 크기/해시 |
| `img/` | 현재27의 실제 화면 3장과 출처 기록 |
| `docs/`, `tools/` | 공개 범위·빌드 전제·입력 검사 |

현행의 선언 재현 입력은 515개입니다. 그 목록을 보존했으며 공개되지 않은 자료를 포함한 완전한 저장소 복구를 약속하지 않습니다. 원본 게임, 전체 원본 유래 그래픽/폰트 덤프, 실행 파일, 세이브, 메모리/체크포인트 덤프, 비공개 패키지는 올리지 않습니다. 글꼴은 프로젝트에서 선택한 Galmuri 원본 TTF 두 개만 OFL 1.1과 함께 넣었습니다. 게임에서 추출한 글꼴은 없습니다.

현재 게임을 실제로 재현한 로컬 검증과 공개 저장소의 소스/입력 검증은 별도입니다. 별도 그래픽 입력과 등록 어셈블러가 없는 새 복제본은 완전한 게임 빌드를 할 수 없습니다. 누락 입력을 다른 이미지나 임의 버전 도구로 대체하지 않습니다.

프로젝트 코드/원고에 들어 있는 과거 실험 경로와 보고서 경로는 이력입니다. 공개 저장소가 PPSSPP를 자동 제어하거나 그 환경을 제공한다는 뜻은 아닙니다. 최신 절차는 `docs/rebuild/README.md`를 사용합니다.
