PPSSPP 설정 안내 — v1.0

저장을 선택했는데 화면만 어두워지고 저장창이 보이지 않는 경우:
해당 게임의 설정 > 그래픽 > ‘버퍼 효과 건너뛰기’를 끄고 게임을 다시 실행하세요.
설정 파일 항목은 [Graphics] SkipBufferEffects=False입니다.
게임별 설정을 사용하면 다른 게임의 전역 설정을 바꾸지 않아도 됩니다.
게임별 설정 파일을 수동 작성할 때는 기존 조작 매핑과 후처리 셰이더를 보존하세요.

2026-10-31 같은 한글 ISO의 분리 PPSSPP GUI 환경에서 저장 목록·덮어쓰기 확인·저장 완료를
확인했습니다. 사용자는 게임별 옵션 적용 후 재실행에서 저장창 정상 표시를 확인했습니다.
이동 입력 이상도 사용자가 PPSSPP 설정 문제였다고 확인했습니다.
이 결과를 패치 코드 결함의 원인 확정이나 모든 저장 경로 검증으로 확대하지 않습니다.

기존 저장은 삭제하거나 변환하지 않습니다. 새 실행에서 일반 ‘불러오기’를 권장합니다.
옛 상태저장에는 이전 자산이 남을 수 있습니다. 사용자 저장 전체를 공개 제보에 첨부하지 마세요.
