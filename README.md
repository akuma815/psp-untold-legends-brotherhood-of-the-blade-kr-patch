## 다운로드 및 적용 방법

아직 공개 릴리즈와 패치 다운로드를 제공하지 않습니다. 이 저장소에는 개발 코드·번역 원고·선별한 검증 메타데이터를 올렸습니다.

1. 소스를 살펴보려면 이 저장소를 복제하거나 **Code → Download ZIP**을 사용합니다. 이는 패치 배포 ZIP이 아닙니다.
2. 개발 환경과 입력 파일 구성은 [소스 안내](docs/SOURCE_GUIDE.md)와 [빌드 안내](docs/rebuild/README.md)를 확인합니다.
3. 게임 원본은 직접 준비해야 합니다. 등록 원본의 크기와 SHA-256은 아래 표와 같습니다.
4. 공개한 입력 검사 도구로 준비 상태를 확인합니다. **별도 그래픽 입력과 어셈블러가 필요하므로 공개 저장소만으로 동일한 전체 빌드를 완성할 수는 없습니다.**

## 주의사항

- 등록 원본은 한국판 식별자 `ULKS46015` / 디스크 버전 `1.01`입니다. 다른 버전 지원은 확인하지 않았습니다.
- 원문 3,973개 중 3,569개와 분리 일지 2개, 합계 **3,571개 문안**을 확정했습니다. 사용처 미확인 404개는 이번 범위에서 제외하고 원문을 유지합니다.
- 한글 지도 25타일과 실제 로딩 문구 1개의 외관을 확정했습니다. 별도 그래픽 13개·타이틀 지도명·제작진은 원문을 유지합니다. 캐릭터 이름 입력은 원래 문자 범위입니다.
- 현재는 사용자 플레이 피드백 단계입니다. 전체 본문 배치·후기·전투·엔딩·실기·다른 버전의 검증은 남아 있습니다.
- 원본 게임·완성 게임 폴더·ISO·세이브·상태 저장·비공개 복구 기록·기존 개인 검수 패키지는 포함하지 않습니다.
- 이번 공개는 소스 저장소 게시이며 최종판·RC·공개 패치 배포나 전체 지원 승인이 아닙니다. **GitHub Release와 태그를 만들지 않았습니다.**
